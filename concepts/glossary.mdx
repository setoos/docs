---
title: Glossary
description: Terminology used throughout the docs
---

| Term | Definition |
|---|---|
| **Agent** | A configured combination of LLM prompt, voice, and tools |
| **Session** | A single call, chat, or WhatsApp conversation instance |
| **Campaign** | A batch of outbound calls/messages sent to a contact list |
| **Execution** | A single run of an agent (one call or chat) |
| **Workflow** | A DAG of automated steps triggered by an event |
| **Tenant** | An isolated customer account/workspace |
| **Webhook** | A callback URL Agentic OS posts events to |
