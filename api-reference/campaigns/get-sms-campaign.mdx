---
title: Get SMS campaign
api: "GET /sms-agent/campaigns/{id}"
description: Retrieve details and message templates of an SMS campaign
---

Retrieves configuration and template mappings of an SMS campaign by its unique UUID.

### Path parameters

<ParamField path="id" type="string" required>
  The unique UUID of the SMS campaign.
</ParamField>

<CodeGroup>

```bash curl
curl -X GET https://dev-agentic-os-campaign-engine-api-aks.setoo.work/api/v1/sms-agent/campaigns/66666666-6666-6666-6666-666666666666 \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://dev-agentic-os-campaign-engine-api-aks.setoo.work/api/v1/sms-agent/campaigns/66666666-6666-6666-6666-666666666666",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
print(response.json())
```
