---
title: Attach WhatsApp number
api: "POST /whatsapp/agents/{agentId}/attach-number"
description: Assign a specific Meta WhatsApp sender number to an agent
---

Sets the dedicated WhatsApp sender phone number override for an agent's campaign.

### Path parameters

<ParamField path="agentId" type="string" required>
  The unique UUID of the agent.
</ParamField>

### Body parameters

<ParamField body="phoneNumberId" type="string" required>
  The Meta `phone_number_id` to use as this agent's sender.
</ParamField>

<CodeGroup>

```bash curl
curl -X POST https://dev-agentic-os-aks.setoo.work/api/v1/whatsapp/agents/11111111-1111-1111-1111-111111111111/attach-number \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "phoneNumberId": "105938472910293"
  }'
```

```python Python
import requests

response = requests.post(
    "https://dev-agentic-os-aks.setoo.work/api/v1/whatsapp/agents/11111111-1111-1111-1111-111111111111/attach-number",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={"phoneNumberId": "105938472910293"},
)
print(response.json())
```
