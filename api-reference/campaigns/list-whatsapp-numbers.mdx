---
title: List WhatsApp phone numbers
api: "GET /whatsapp/fetch-numbers"
description: Retrieve registered WhatsApp sender phone numbers from Meta
---

Queries Meta to fetch all registered sender phone numbers associated with your connected WhatsApp Business Account.

<CodeGroup>

```bash curl
curl -X GET https://dev-agentic-os-aks.setoo.work/api/v1/whatsapp/fetch-numbers \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://dev-agentic-os-aks.setoo.work/api/v1/whatsapp/fetch-numbers",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
print(response.json())
```

```javascript Node
const response = await fetch(
  "https://dev-agentic-os-aks.setoo.work/api/v1/whatsapp/fetch-numbers",
  {
    method: "GET",
    headers: { Authorization: `Bearer ${API_KEY}` },
  },
);
const data = await response.json();
console.log(data);
```
