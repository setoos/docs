description: Retrieve webhook callback URL and verify token for Meta integration
---

Fetches the webhook configuration details needed to configure webhook callbacks in the Meta Developer App portal.

<CodeGroup>

```bash curl
curl -X GET https://dev-agentic-os-campaign-engine-api-aks.setoo.work/api/v1/whatsapp/webhook-details \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://dev-agentic-os-campaign-engine-api-aks.setoo.work/api/v1/whatsapp/webhook-details",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
print(response.json())
```

```javascript Node
const response = await fetch(
  "https://dev-agentic-os-campaign-engine-api-aks.setoo.work/api/v1/whatsapp/webhook-details",
  {
    method: "GET",
    headers: { Authorization: `Bearer ${API_KEY}` },

console.log(data);
```
