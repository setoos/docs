---
title: Delete SMS campaign
api: "DELETE /sms-agent/campaigns/{id}"
description: Delete an SMS campaign and its templates
---

Permanently deletes an SMS campaign configuration.

### Path parameters

<ParamField path="id" type="string" required>
  The unique UUID of the SMS campaign to delete.
</ParamField>

<CodeGroup>

```bash curl
curl -X DELETE https://dev-agentic-os-campaign-engine-api-aks.setoo.work/api/v1/sms-agent/campaigns/66666666-6666-6666-6666-666666666666 \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY"
```

```python Python
import requests

response = requests.delete(
    "https://dev-agentic-os-campaign-engine-api-aks.setoo.work/api/v1/sms-agent/campaigns/66666666-6666-6666-6666-666666666666",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
print(response.status_code)
```


</CodeGroup>

### Response

`204 No Content` on successful deletion.
