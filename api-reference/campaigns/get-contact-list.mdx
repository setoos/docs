---
title: Get contact list
api: "GET /contact-lists/{id}"
description: Retrieve details of a single contact list
---

Retrieves metadata and information for a specific contact list by its unique ID.

### Path parameters

<ParamField path="id" type="string" required>
  The unique UUID of the contact list.
</ParamField>

<CodeGroup>

```bash curl
curl -X GET https://dev-agentic-os-campaign-engine-api-aks.setoo.work/api/v1/contact-lists/33333333-3333-3333-3333-333333333333 \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://dev-agentic-os-campaign-engine-api-aks.setoo.work/api/v1/contact-lists/33333333-3333-3333-3333-333333333333",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
print(response.json())
```
