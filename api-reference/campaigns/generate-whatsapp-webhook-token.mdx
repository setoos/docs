---
title: Generate WhatsApp webhook token
api: "POST /whatsapp/webhook-token"
description: Generate or retrieve the persistent webhook verify token
---

Generates a secure verification token for Meta webhook subscription verification. If a token already exists for the tenant, returns the existing token idempotently.

<CodeGroup>

```bash curl
curl -X POST https://api.agentic-os.com/api/v1/whatsapp/webhook-token \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```

```python Python
import requests

response = requests.post(
    "https://api.agentic-os.com/api/v1/whatsapp/webhook-token",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={},
)
print(response.json())
```

```javascript Node
const response = await fetch(
  "https://api.agentic-os.com/api/v1/whatsapp/webhook-token",

console.log(data);
```
