---
title: Get contact
api: "GET /contact-lists/{listId}/contacts/{id}"
description: Retrieve details for a single contact in a contact list
---

Retrieves a single contact record by its UUID.

### Path parameters

<ParamField path="listId" type="string" required>
  The unique UUID of the contact list.
</ParamField>

<ParamField path="id" type="string" required>
  The unique UUID of the contact.
</ParamField>

```bash curl
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY"
```
