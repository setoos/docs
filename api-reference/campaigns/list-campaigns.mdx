---
title: List campaigns
api: "GET /campaigns"
description: List campaigns for the tenant
---

Returns a paginated list of the campaigns belonging to your tenant.

### Query parameters

<ParamField query="status" type="string">
  Filter by campaign status — one of `DRAFT`, `SCHEDULED`, `RUNNING`, `PAUSED`,
  `COMPLETED`, `FAILED`
</ParamField>

<ParamField query="page" type="integer" default="1">
  1-based page number
</ParamField>

<ParamField query="pageSize" type="integer" default="15">
  Items per page, maximum 100
</ParamField>
