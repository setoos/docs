Agentic OS provides a multi-channel campaign engine designed for high-scale outbound communications. Campaigns allow you to reach hundreds or thousands of contacts automatically with intelligent pacing, retry policies, call window guardrails, and post-call messaging.

## API Summary

### Voice Campaigns (`/campaigns`)

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/campaigns` | Create a new voice campaign |
| `GET` | `/campaigns` | List all voice campaigns with pagination |
| `GET` | `/campaigns/{id}` | Get campaign configuration and current status |
| `GET` | `/campaigns/{id}/summary` | Get aggregated progress, attempt statistics, and time estimates |
| `PATCH` | `/campaigns/{id}` | Update campaign settings (DRAFT only) |
| `POST` | `/campaigns/{id}/start` | Start immediate outbound dialing |
| `POST` | `/campaigns/{id}/schedule` | Schedule campaign to start at its `scheduledAt` timestamp |
| `POST` | `/campaigns/{id}/pause` | Pause a running campaign |
| `POST` | `/campaigns/{id}/resume` | Resume a paused campaign |
| `POST` | `/campaigns/{id}/abort` | Abort a running or scheduled campaign |
| `POST` | `/campaigns/{id}/regenerate` | Create a follow-up campaign for specific call dispositions |
| `GET` | `/campaigns/{campaignId}/attempts` | List individual contact call attempts |
| `GET` | `/campaigns/{campaignId}/attempts/stats` | Get attempt status breakdown |
| `GET` | `/campaigns/{campaignId}/attempts/final-summary` | Get final disposition counts |
| `DELETE` | `/campaigns/{id}` | Delete a campaign and its attempt history |

### Contact Lists & Contacts (`/contact-lists`)

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/contact-lists` | Create a new contact list |
| `GET` | `/contact-lists` | List all contact lists |
| `GET` | `/contact-lists/{id}` | Get contact list details |
| `PATCH` | `/contact-lists/{id}` | Update contact list name or metadata |
| `DELETE` | `/contact-lists/{id}` | Delete a contact list |
| `POST` | `/contact-lists/{id}/upload` | Upload CSV contacts (max 500 rows) |
| `POST` | `/contact-lists/{listId}/contacts` | Add a single contact |
| `POST` | `/contact-lists/{listId}/contacts/bulk` | Bulk add contacts (up to 5,000) |
| `GET` | `/contact-lists/{listId}/contacts` | List contacts with pagination |
| `GET` | `/contact-lists/{listId}/contacts/{id}` | Get single contact details |
| `PATCH` | `/contact-lists/{listId}/contacts/{id}` | Update contact details |
| `DELETE` | `/contact-lists/{listId}/contacts/{id}` | Delete a contact |
| `POST` | `/contact-lists/{listId}/contacts/delete-batch` | Batch delete contacts by IDs |
