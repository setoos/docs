---
title: Trigger run
api: "POST /workflows/{workflowId}/runs"
description: Manually trigger a workflow execution
---

### Path parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `workflowId` | string | Yes | The workflow ID |

### Body parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `triggerData` | object | No | Data available to the first step |

<CodeGroup>

```bash curl
curl -X POST https://api.agentic-os.com/api/v1/workflows/WORKFLOW_ID/runs \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "triggerData": { "contactId": "abc123" } }'
```

</CodeGroup>

### Response

```json
{ "id": "run_990e8400-...", "queued": true, "workflowId": "WORKFLOW_ID" }
```
