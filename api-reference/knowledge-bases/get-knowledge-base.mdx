---
title: Get knowledge base
api: "GET /knowledge-bases/{id}"
description: Retrieve a single knowledge base by ID
---

### Path parameters

<ParamField path="id" type="string" required>
  The knowledge base ID
</ParamField>

<CodeGroup>

```bash curl
curl https://prod-comms-engine-api.20x.business/api/v1/knowledge-bases/KB_ID \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY"
```

```python Python
requests.get(
    "https://prod-comms-engine-api.20x.business/api/v1/knowledge-bases/KB_ID",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
```

```javascript Node
await fetch("https://prod-comms-engine-api.20x.business/api/v1/knowledge-bases/KB_ID", {
  headers: { Authorization: `Bearer ${API_KEY}` },
});
```

</CodeGroup>
