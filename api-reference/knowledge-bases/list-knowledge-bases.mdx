---
title: List knowledge bases
api: "GET /knowledge-bases"
description: List the knowledge bases in your tenant
---

Returns every knowledge base belonging to your tenant.

<CodeGroup>

```bash curl
curl https://dev-agentic-os-aks.setoo.work/api/v1/knowledge-bases \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY"
```

```python Python
requests.get(
    "https://dev-agentic-os-aks.setoo.work/api/v1/knowledge-bases",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
```

```javascript Node
await fetch("https://dev-agentic-os-aks.setoo.work/api/v1/knowledge-bases", {
  headers: { Authorization: `Bearer ${API_KEY}` },
});
```

</CodeGroup>
