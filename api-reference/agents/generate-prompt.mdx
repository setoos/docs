---
title: Enhance agent prompt
api: "POST /agents/{id}/generate-prompt"
description: Generate a system prompt, greeting and fallback from a plain-language instruction
---

Turns a short description of what you want the agent to do into a full system
prompt, opening greeting and fallback line. Use it to bootstrap an agent's
behaviour instead of writing prompts by hand, then persist the result with
[Patch update agent](/api-reference/agents/patch-update-agent).

This calls the AI engine, so it is slower than the other agent endpoints.

### Path parameters

<ParamField path="id" type="string" required>
  The agent ID
</ParamField>

### Body parameters

The body is forwarded to the AI engine. The useful field is a natural-language
instruction describing the agent's job.

<ParamField body="instruction" type="string">
  What the agent should do, in plain language — e.g. "Book dental appointments
  and confirm insurance details"
</ParamField>

<CodeGroup>

```bash curl
curl -X POST https://api.agentic-os.com/api/v1/agents/AGENT_ID/generate-prompt \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "instruction": "Book dental appointments and confirm insurance details" }'
```

```python Python
requests.post(
    "https://api.agentic-os.com/api/v1/agents/AGENT_ID/generate-prompt",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={"instruction": "Book dental appointments and confirm insurance details"},
)
```

```javascript Node
await fetch(
  "https://api.agentic-os.com/api/v1/agents/AGENT_ID/generate-prompt",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      instruction: "Book dental appointments and confirm insurance details",
    }),
  },
);
```
