---
title: Create agent
api: "POST /agents"
description: Create a new AI voice agent
---

Create a new agent with an LLM prompt, model, and optional knowledge base.

### Body parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `name` | string | Yes | Agent display name |
| `agent_prompt` | string | Yes | System prompt defining behavior |
| `llm_model_id` | string | Yes | LLM model to use, e.g. `gpt-4-turbo` |
| `knowledge_base_id` | string | No | Attach a knowledge base |
| `is_active` | boolean | No | Defaults to `true` |

<CodeGroup>

```bash curl
curl -X POST https://api.agentic-os.com/api/v1/agents \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Support Agent",
    "agent_prompt": "You are a helpful customer support agent.",
    "llm_model_id": "gpt-4-turbo",
    "is_active": true
  }'
```

```python Python
requests.post(
    "https://api.agentic-os.com/api/v1/agents",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "name": "Support Agent",
        "agent_prompt": "You are a helpful customer support agent.",
        "llm_model_id": "gpt-4-turbo",
        "is_active": True,
    },
)
```

