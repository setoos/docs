---
title: Update agent
api: "PUT /agents/{id}"
description: Replace an agent's full configuration
---

Replace the agent's entire configuration. Any field not included is reset to its
default — use [Patch update agent](/api-reference/agents/patch-update-agent) for
partial updates.

### Path parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `id` | string | Yes | The agent ID |

<CodeGroup>

```bash curl
curl -X PUT https://api.agentic-os.com/api/v1/agents/AGENT_ID \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Support Agent v2",
    "agent_prompt": "You are an updated support agent.",
    "llm_model_id": "gpt-4-turbo",
    "is_active": true
  }'
```

```python Python
requests.put(
    "https://api.agentic-os.com/api/v1/agents/AGENT_ID",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "name": "Support Agent v2",
        "agent_prompt": "You are an updated support agent.",
        "llm_model_id": "gpt-4-turbo",
        "is_active": True,
    },
)
```

</CodeGroup>
