---
title: Delete agent
api: "DELETE /agents/{id}"
description: Permanently delete an agent
---

<Callout type="warning">
  This action cannot be undone. All associated call logs and analytics are deleted
  along with the agent. This endpoint's exact behavior is not independently
  verified in this documentation set — confirm on a test agent before relying on
  it in production.
</Callout>

### Path parameters

<ParamField path="id" type="string" required>
  The agent ID
</ParamField>

<CodeGroup>

```bash curl
curl -X DELETE https://dev-agentic-os-aks.setoo.work/api/v1/agents/AGENT_ID \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY"
```

```python Python
requests.delete(
    "https://dev-agentic-os-aks.setoo.work/api/v1/agents/AGENT_ID",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
```

</CodeGroup>

### Response

Returns `204 No Content` on success.
