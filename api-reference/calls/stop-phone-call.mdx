---
title: Stop phone call
description: Ending a single live call
---

<Callout type="warning">
  There is currently no verified endpoint for stopping one specific in-progress
  call by session ID. If you need to end every live call for an agent at once
  (e.g. as a kill switch), use
  [Stop agent calls](/api-reference/agents/stop-agent-calls) instead.
</Callout>
