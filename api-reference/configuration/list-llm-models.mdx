---
title: List LLM models
api: "GET /llm/models"
description: List the language models available to power your agents
---

Returns the LLM models you can assign to an agent. Pass a model `id` as
`llm_model_id` when [creating](/api-reference/agents/create-agent) or
[updating](/api-reference/agents/patch-update-agent) an agent.

Providers are listed separately at `GET /llm/providers`.

<CodeGroup>

```bash curl
curl https://dev-agentic-os-comms-engine-api-aks.setoo.work/api/v1/llm/models \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY"
```

