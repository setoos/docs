See [Make phone call](/api-reference/calls/make-phone-call) for the full request
reference. This guide covers common patterns.

## Webhooks

Register a webhook to be notified when a call ends, instead of polling:

```bash
curl -X PATCH https://api.agentic-os.com/api/v1/agents/AGENT_ID \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "webhook_url": "https://yourapp.com/webhooks/agentic-os" }'
```

Agentic OS POSTs a payload with `sessionId`, `status`, `transcript`, and
`recording` once the call completes.

## Passing dynamic variables

Inject per-call variables (e.g. customer name) into the prompt:

```json
{
  "agentId": "AGENT_ID",
  "to": "+919876543210",
  "from": "+1XXXXXXXXXX",
  "provider": "PLIVO",
  "variables": { "customer_name": "Asha" }
}
```
