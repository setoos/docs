---
title: Batch Calling
description: Run large outbound campaigns
---

For campaigns beyond a few dozen calls, use the
[Campaigns API](/api-reference/campaigns/create-campaign) rather than calling
`/channels/voice/call` per contact — it handles pacing and reporting.

Campaigns call a **contact list** you build first, not inline contacts. See
[Create campaign](/api-reference/campaigns/create-campaign) for the full
create-list → add-contacts → create-campaign → start flow.

Monitor progress with
[Get campaign](/api-reference/campaigns/get-campaign).
