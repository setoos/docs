---
title: Receive Incoming Calls
description: Route inbound calls to an agent
---

Assign an agent to a number so inbound calls are answered automatically.

```bash
curl -X PATCH https://api.agentic-os.com/api/v1/numbers/NUMBER_ID \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "agentId": "AGENT_ID" }'
```

Once assigned, any call to that number is answered by the agent — no additional
setup is required. Call logs and transcripts appear the same way as outbound calls.
