---
title: Hangup Live Calls
description: End a specific in-progress call
---

See [Stop phone call](/api-reference/calls/stop-phone-call) — pass the call's
`sessionId` to terminate it immediately.

```bash
curl -X POST https://api.agentic-os.com/api/v1/channels/voice/call/SESSION_ID/stop \
  -H "Authorization: Bearer $AGENTIC_OS_API_KEY"
```
