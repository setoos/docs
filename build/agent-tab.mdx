---
title: Agent Tab
description: Name, description, and system prompt
---

| Field | Description |
|---|---|
| Name | Display name shown in the dashboard and call logs |
| Description | Internal note describing the agent's purpose |
| System Prompt | The prompt that defines the agent's behavior and personality |
| Welcome Message | First line the agent speaks/sends |
| Active | Whether the agent can currently be called |

See [Create an Agent](/guides/quickstarts/api-quickstart) for prompt-writing tips.
