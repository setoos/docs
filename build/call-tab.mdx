---
title: Call Tab
description: Call termination, silence timeout, and telephony
---

| Field | Description | Default |
|---|---|---|
| Max Call Duration | Longest a call can run before it's ended automatically | 90 seconds |
| Silence Timeout | Hang up after this much silence from the caller | 10 seconds |
| Telephony Provider | Provider used for this agent's calls | Tenant default |
| Caller ID | Phone number shown as caller ID for outbound calls | — |

Configure the underlying telephony credentials once under **Integrations** — see
[Purchase Phone Numbers](/guides/numbers/purchase-phone-numbers).
