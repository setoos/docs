---
title: Account Tools
description: The six MCP tools for profile, pricing, cost estimates, wallet balance and billing currency
---

Six tools. Deliberately narrow — this is the area where most of what exists in the
platform is not reachable by an assistant at all.

Group name for `?tools=`: **`account`**

## get_profile

Returns your name, email, role and organisation details.

**Permission:** `profile:read` · **Destructive:** no

Never includes wallet balance or anything billing-related.

```
Which 20X account am I connected to?
```

## update_profile

Changes your first name, last name, or both.

**Permission:** `profile:write` · **Destructive:** no

That is the entire scope of it. Email, password and role cannot be changed through MCP.

```
Change my first name to Vaibhav.
```

## get_pricing_rate_card

Returns the current published rate card — what each component costs per unit.

**Permission:** `pricing:read` · **Destructive:** no

Published prices, not your balance. For what you have actually spent, use
`list_usage_records` in the reporting group.

```
What does a minute of calling cost?
```

## estimate_agent_cost

Estimates the per-minute cost of an agent, either an existing one or a configuration
you are considering.

**Permission:** `pricing:read` · **Destructive:** no

```
What will my "Sales qualifier" agent cost per minute?
Would switching to a cheaper model save much?
```

## get_wallet_balance

Returns the current wallet balance and currency.

**Permission:** `wallet:read` · **Destructive:** no

Balance and currency, nothing else. No transactions, no invoices, no payment details.

It exists so an assistant can check there are funds before doing something that spends
— starting a campaign, buying a number.

```
What's my wallet balance?
Do I have enough balance to run the October campaign?
```

## set_billing_currency

Switches the organisation's billing currency between **USD** and **INR**.

**Permission:** `currency:write` · **Asks you to confirm:** yes

```
Change my billing currency to dollars.
```

Your existing wallet balance is converted at the live exchange rate, so its value
stays the same while the figure changes. No money is added or removed.

It also sets which payment gateway a later top-up runs through (INR → Razorpay,
USD → Stripe) and the currency costs are quoted in across Logs, Dashboard and
Campaigns.

Two things worth knowing:

- The permission is **unticked by default**, so you grant it deliberately.
- USD and INR are the only supported values. Anything else is rejected rather than
  ignored.
- Switching back will not land on exactly the original figure, because each
  conversion rounds.

This is the only tool that writes to a billing route. It is here rather than excluded
because it moves nothing in or out of the wallet — it re-denominates what is already
there. Behaviour is identical to the Billing Currency control on the Profile page, so
an assistant and a person produce the same result.

## What is not here, and why

There is no tool for any of the following, and no permission that could enable one:

- Adding money to the wallet — recharge, checkout, plan or addon purchase
- Invoices, transaction history, the billing profile, payment methods
- Saved integration credentials and connected provider balances
- API keys and service tokens
- Users and roles

The rule: **spending an existing balance on platform work can be granted. Adding to that
balance never can.**

`set_billing_currency` is the one case that sits on the line rather than either side of
it, and it was added deliberately after review: it neither spends nor adds, it changes
the unit the balance is denominated in.

That line is why `start_campaign` and `purchase_phone_number` exist while recharge does
not. An assistant holding every permission we issue can spend a funded wallet down to
zero and then stops. It cannot top itself up, so the worst case is bounded by whatever
you chose to put in the wallet.
