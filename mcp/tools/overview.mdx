64 tools. 33 only read, 16 create or change something, and 15 are flagged
destructive.

Each is a thin wrapper over one REST endpoint, so a tool behaves exactly as the
equivalent [API call](/api-reference/introduction) would.

## What "destructive" means here

Two kinds of thing, both flagged the same way because both deserve a pause:

- **Irreversible** — the eight deletes, and aborting a campaign.
- **Real-world effect** — places calls, sends messages, spends wallet balance, or
  takes a capability away from something that was working.

Most clients ask you to confirm before running one. That prompt is a convenience, not
the control: a client is free to ignore the flag, and people click through prompts.
The actual protection is that these tools need their own permission — `campaigns:execute`
is separate from `campaigns:write`, and each delete needs its own `*:delete`.

## The 15 destructive tools, in one place

`delete_agent` · `delete_campaign` · `delete_contacts` · `delete_contact_list` ·
`delete_knowledge_source` · `delete_knowledge_base` · `delete_whatsapp_campaign` ·
`delete_sms_campaign` · `start_campaign` · `schedule_campaign` · `resume_campaign` ·
`abort_campaign` · `purchase_phone_number` · `initiate_call` · `assign_voice_number`

`assign_voice_number` is on the list for a reason that is easy to miss: if the number
already belongs to another agent, linking it moves it, and that agent immediately
stops being able to call or receive on it.

`pause_campaign` is not on the list — pausing is reversible — but it still needs
`campaigns:execute`, because interrupting something live is an execution decision.

## Tools that do not exist

Asked for one of these, an assistant will not find it. That is deliberate, not a gap:

| Not available | Why |
| :--- | :--- |
| Upload a file to a knowledge base | Tool arguments are JSON, and the server cannot see your disk. Use `add_knowledge_text`. |
| Read back stored knowledge text, or search a knowledge base | Would be a bulk export of your internal documents through a chat client. |
| Release a phone number | No undo, no refund. |
| Anything touching wallet top-up, invoices, payment details, credentials, API keys, users or roles | No permission exists for these. See [Permissions](/mcp/permissions). |
| Workflows | There is no workflow API to wrap yet. |

## Narrowing what is advertised

A connection can expose a subset by appending `?tools=` to the endpoint. This is
necessary in Cursor, which drops tools past roughly the first 40 —
[details and group names](/mcp/clients/cursor#available-groups).
