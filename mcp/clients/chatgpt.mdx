---
title: Connect ChatGPT
description: Add 20X as a custom MCP plugin in ChatGPT
---

```
https://mcp.20x.business/mcp
```

<Callout type="info">
  ChatGPT asks you to confirm before it changes anything in 20X. Reads run without
  asking.
</Callout>

<Steps>
  <Step title="Open your personal plugins">
    In ChatGPT on the web, open **Plugins** and go to the **Personal** tab. Select
    **Add**, then **Add custom MCP server**.
  </Step>

  <Step title="Fill in the form">
    - **Name**: `20X`
    - **Connection**: choose **Server URL** and paste the endpoint above.
    - **Authentication**: **OAuth**. Do not paste an API key.
  </Step>

  <Step title="Create the plugin">
    Tick **I understand and want to continue**, then select **Create as a plugin**.
  </Step>

  <Step title="Approve the permissions">
    A 20X screen opens listing what ChatGPT is asking to do. Read-only permissions
    are pre-ticked. Tick anything further you want to allow, then approve.

    See [Permissions](/mcp/permissions) for what each one means.
  </Step>

  <Step title="Check it worked">
    In a new chat, type `@`, select **20X**, and ask:

    ```
    List my 20X agents.
    ```

    Getting your agents back means the connection is live. If 20X does not appear
    after `@`, install it from **Plugins → Personal** first.
  </Step>
</Steps>

## If something is off

| Symptom | Cause |
| :--- | :--- |
| No **Add custom MCP server** option | In a work workspace, an admin has not allowed **Create plugins with MCPs**. |
| ChatGPT stops before changing something | Expected. Approve the confirmation in the chat. |
| An error naming a permission | That permission was not ticked. Reconnect and tick it. |

More in [Troubleshooting](/mcp/troubleshooting).
